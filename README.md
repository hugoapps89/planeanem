# PlaneaNEM — interfaz basada en referencia

Página estática recreada a partir de la captura proporcionada.

Archivos:
- index.html
- style.css
- app.js

La interfaz incluye navegación, dashboard, nueva planeación, planeaciones recientes, modal de generación y páginas auxiliares.

Para GitHub/Render:
1. Sube estos archivos a la raíz de un repositorio.
2. En Render crea un Static Site.
3. Conecta el repositorio.
4. Publish Directory: `.`
5. No necesita build command.

La IA todavía es simulada. Para producción se debe conectar mediante un backend y nunca exponer la API key en el navegador.
